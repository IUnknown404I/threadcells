# Происхождение

ThreadCells — независимый downstream, созданный на основе AWS Labs CLI Agent Orchestrator. Сохранённые вышестоящие лицензия и атрибуция находятся в файлах `LICENSE` и `NOTICE` кандидата исходного кода. Этот репозиторий сохраняет совместимые внутренние имена и команды `cao`, когда они поддерживают существующее поведение; в публичных поверхностях продукта используется ThreadCells. Не подразумеваются ни спонсорство, ни одобрение со стороны AWS.

Каждый локальный кандидат фиксирует закоммиченную ревизию исходного кода, файловый манифест, контрольные суммы SHA-256 и свидетельства прямых зависимостей в `candidate-manifest.json`, `SHA256SUMS` и `sbom.cdx.json`. SBOM — свидетельство заявленных/разрешённых прямых зависимостей, а не разрешение вопросов лицензирования, оценка уязвимостей или заявление о паритете с upstream. Публичная дистрибуция по-прежнему требует одобрения owner публичного репозитория, контакта по безопасности, происхождения брендинга и проверки зависимостей/лицензий.
