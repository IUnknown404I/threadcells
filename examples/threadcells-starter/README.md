# ThreadCells starter: bounded documentation change

This starter is a safe, non-production exercise for one trusted local host. It demonstrates the handoff shape without credentials, external publication, service changes, private data, or destructive commands.

1. Create three local profiles from `supervisor.md`, `developer.md`, and `reviewer.md` using your existing ThreadCells profile workflow.
2. Start the supervisor with a single harmless task, such as updating a scratch Markdown file in a disposable Git repository.
3. Let the supervisor delegate only the developer and reviewer prompts below.
4. Read the returned result before you decide whether to make any real change.

The example intentionally has no autonomous merge, push, release, or deployment step. It is a collaboration pattern, not a security boundary.

See [DEMO.md](DEMO.md) for the expected synthetic result flow.
