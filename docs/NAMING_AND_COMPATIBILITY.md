# Naming and compatibility

ThreadCells is the public product name and `threadcells*` is the canonical command family. Existing `cao`, `cao-server`, `cao-mcp-server`, `cao-resource-status`, `cao-heavy-run`, and `cao-housekeeping` commands remain supported compatibility entry points. The Python import namespace and durable state identifiers remain `cli_agent_orchestrator`/CAO-compatible in this preview.
