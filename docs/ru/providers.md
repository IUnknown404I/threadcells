# Провайдеры

Провайдер — это нативный CLI coding-agent, который фактически выполняет ход модели. ThreadCells предоставляет адаптер вокруг этого CLI, чтобы запуск, статус терминала, отмена, отчёт о возможностях и доступная телеметрия использования имели единый вид.

## Три разных факта

Экраны провайдеров намеренно разделяют три факта, которые легко спутать:

| Факт | Значение |
| --- | --- |
| Встроенный адаптер | Эта сборка ThreadCells содержит проверенный код интеграции с провайдером. |
| CLI установлен | Требуемый исполняемый файл находится в `PATH` runtime user. |
| Готов | Предварительная проверка считает установленный CLI совместимым и аутентифицированным либо CLI не может безопасно раскрыть состояние аутентификации. |

Settings → Провайдеры перечисляет адаптеры, в том числе те, чья внешняя команда отсутствует. Spawn Agent использует ту же каноническую предварительную проверку и отключает провайдеры, чья недоступность доказана.

Например, **Built-in adapter · CLI not installed** не противоречит сам себе. Это значит, что ThreadCells умеет работать с провайдером, но на хосте сейчас нет программы этого провайдера.

## Встроенные провайдеры

Текущая сборка регистрирует следующие адаптеры:

| Провайдер | Каноническая команда |
| --- | --- |
| Amazon Q Developer | `q` |
| Claude Code | `claude` |
| Codex | `codex` |
| Gemini CLI | `gemini` |
| GitHub Copilot CLI | `copilot` |
| Kimi CLI | `kimi` |
| Kiro CLI | `kiro-cli` |
| OpenCode CLI | `opencode` |

Регистрация означает фактическую поддержку продукта, а не указание устанавливать каждый CLI. Устанавливайте только провайдеры, которыми собираетесь пользоваться, следуя официальным инструкциям и процедуре аутентификации соответствующего провайдера.

## Матрица совместимости

Эта матрица описывает контракт адаптера в данном релизе, а не обещает, что любая версия внешнего CLI или учётная запись готовы на конкретном хосте. **Поддерживается** означает, что адаптер реализует возможность напрямую, **Условно** — что поведение зависит от CLI провайдера или режима сессии, а **Не сообщается** — что ThreadCells не выдумывает данные.

| Провайдер | Запуск/отмена | Возобновление и сохранность | Структурированное завершение | Телеметрия использования | Управление моделью/рассуждением | Проверка готовности |
| --- | --- | --- | --- | --- | --- | --- |
| Codex | Поддерживается | Условное возобновление; сохранность поддерживается | Условно | Поддерживаются нативные поля токенов провайдера | Поддерживается | Команда, версия и аутентификация |
| Claude Code | Поддерживается | Условно | Условно | Условные нативные поля провайдера | Поддерживается выбор модели; прочие элементы управления зависят от адаптера | Команда, версия и аутентификация |
| Amazon Q Developer | Поддерживается | Условно | Условно | Не сообщается | Условно | Команда и версия; аутентификация не проверена |
| Gemini CLI | Поддерживается | Условно | Условно | Не сообщается | Условно | Команда и версия; аутентификация не проверена |
| GitHub Copilot CLI | Поддерживается | Условно | Условно | Не сообщается | Условно | Команда и версия; аутентификация не проверена |
| Kimi CLI | Поддерживается | Условно | Условно | Не сообщается | Условно | Команда и версия; аутентификация не проверена |
| Kiro CLI | Поддерживается | Условно | Условно | Не сообщается | Условно | Команда и версия; аутентификация не проверена |
| OpenCode CLI | Поддерживается | Условно | Условно | Не сообщается | Условно | Команда и версия; аутентификация не проверена |

Codex — эталонный провайдер для проверки релизов. Другими встроенными адаптерами можно пользоваться, если их публичная предварительная проверка допускает запуск, однако нативное поведение провайдера и аутентификация могут различаться. Представление возможностей в работающем Settings является источником истины для установленной сборки.

## Метки доступности

ThreadCells нормализует предварительную проверку в пять состояний для оператора:

- **Готов** (`INSTALLED_AND_READY`): установлен, совместим и аутентифицирован, если аутентификацию можно проверить.
- **Требуется аутентификация** (`INSTALLED_NOT_AUTHENTICATED`): команда существует, но провайдер сообщает, что требуется вход.
- **Установлен, но нездоров** (`INSTALLED_BUT_UNHEALTHY`): установлен, но несовместим или не проходит проверку состояния/версии.
- **CLI не установлен** (`NOT_INSTALLED`): канонический исполняемый файл не найден для runtime user ThreadCells.
- **Готовность не проверена** (`UNKNOWN`): установлен и не признан недоступным, но провайдер не может безопасно проверить аутентификацию или готовность без взаимодействия.

Непроверенный провайдер может оставаться доступным для запуска, когда его команда установлена, совместима и неизвестно только состояние аутентификации. Запуск всё равно может завершиться нативным приглашением провайдера к входу; изучите его терминал и пройдите аутентификацию провайдера вне ThreadCells.

## Проверьте представление runtime user

Доступность провайдера зависит от учётной записи, запускающей ThreadCells, а не от вашей интерактивной оболочки. Сначала проверьте через ThreadCells:

```bash
threadcells providers list
threadcells doctor
```

Затем от имени runtime user проверьте ожидаемый бинарный файл и его версию. Для Codex:

```bash
command -v codex
codex --version
codex login status
```

Используйте собственную команду состояния провайдера, если она существует. Не копируйте личные каталоги учётных данных провайдера в service account. Аутентифицируйте эту учётную запись поддерживаемым провайдером способом.

## Settings и Spawn Agent

Settings → Провайдеры — это представление инвентаря и диагностики. Здесь показаны идентичность адаптера, конфигурация, возможности, наличие команды, версия, состояние аутентификации и безопасное для публикации сообщение предварительной проверки.

Spawn Agent — представление запуска. Его включённое или отключённое состояние выводится из того же результата предварительной проверки. Если после обновления два представления не совпадают, считайте это дефектом продукта, а не пытайтесь угадать, какая метка верна.

## Возможности зависят от провайдера

Адаптеры объявляют, поддерживаются ли возобновление, структурированное завершение, выбор модели, управление рассуждением, сохранность сессии и использование, доступны условно или не поддерживаются. ThreadCells не имитирует неподдерживаемую возможность.

Codex — эталонный адаптер и предоставляет точную накопительную телеметрию использования для поддерживаемых полей токенов. Claude Code условно поддерживает некоторые возможности использования и завершения. Другие адаптеры могут не сообщать использование; их поля Statistics остаются недоступными, а не оцениваются.

## Конфигурация и секреты

Конфигурация провайдера декларативна. Она может выбрать установленный адаптер и принадлежащие адаптеру настройки, но не может импортировать путь к бинарному файлу, команду оболочки, аргументы, переменные окружения, пароли, токены или необработанные учётные данные.

Непрозрачные `secret_refs` могут именовать секрет, разрешаемый доверенным кодом адаптера. Публичные ответы списков и экспорта опускают или редактируют их значения. Пакеты адаптеров провайдера — исполняемый доверенный код, который должен устанавливаться и проверяться оператором хоста.

## Устранение неполадок

### Провайдер показывает «CLI не установлен»

Запустите `command -v` от имени service account и сравните его `PATH` с вашей оболочкой. Установите каноническую команду провайдера, только если собираетесь ею пользоваться, затем перезапустите или обновите предварительную проверку.

### Установлен, но требуется аутентификация

Запустите официальную процедуру входа провайдера от имени runtime user. Предварительная проверка ThreadCells никогда не аутентифицирует от вашего имени и не включает настройки обхода разрешений.

### Готовность не проверена

Команда существует, но не имеет безопасной неинтерактивной проверки готовности. Проверьте версию и выполните небольшой нативный тест провайдера. Запуск ThreadCells может стать первой окончательной проверкой готовности.

### Установлен, но нездоров

Прочитайте безопасную причину предварительной проверки. Частые причины: ошибка команды версии, известная несовместимая версия или исполняемый файл, который завершается неожиданно. Обновите или исправьте внешний CLI; не изменяйте реестр адаптеров, чтобы пометить его готовым.

### Запуск не удаётся при состоянии «Готов»

Откройте вывод терминала. Учётные данные могли истечь после предварительной проверки, выбранная модель может быть недоступна или могло измениться состояние сервиса провайдера.

Подробности расширенной интеграции см. в [Разработке адаптеров провайдеров](PROVIDER_ADAPTERS.md). О том, чем управляет профиль запуска, см. [Профили](PROFILES.md).
