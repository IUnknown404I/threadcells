# Support

ThreadCells is a technical preview. Use the [public Issue forms](https://github.com/IUnknown404I/threadcells/issues/new/choose) for unresolved, actionable bugs, enhancements, and documentation problems that satisfy the [Issue policy](docs/ISSUES.md).

Check the [documentation](https://iunknown404i.github.io/threadcells/docs/) and [Troubleshooting](docs/TROUBLESHOOTING.md) before reporting a problem. The project does not currently offer a general-support forum. Security-sensitive reports must follow the private route in [SECURITY.md](SECURITY.md).

Never post secrets, personal data, private paths, state databases, private messages, or terminal transcripts publicly.
