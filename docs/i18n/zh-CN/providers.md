# 提供商

提供商是实际运行模型回合的原生编码代理 CLI。ThreadCells 会在该 CLI 外提供适配器，使启动、终端状态、取消、能力报告及可用的用量遥测具有统一的形式。

## 三个不同的事实

提供商页面刻意区分了三个容易混淆的事实：

| 事实 | 含义 |
| --- | --- |
| 内置适配器 | 此 ThreadCells 构建包含已审查的该提供商集成代码。 |
| CLI 已安装 | 所需可执行文件位于运行时用户的 `PATH` 中。 |
| 就绪 | 预检认为已安装的 CLI 兼容且已认证，或该 CLI 无法安全地公开认证状态。 |

Settings → Providers 会列出适配器，包括外部命令不存在的适配器。Spawn Agent 使用同一套权威预检，并禁用已确定不可用的提供商。

例如，**内置适配器 · CLI 未安装** 并不矛盾。这表示 ThreadCells 知道如何运行该提供商，但主机当前没有该提供商的程序。

## 可用性标签

ThreadCells 将预检规范化为五种面向操作员的状态：

- **就绪** (`INSTALLED_AND_READY`)：已安装、兼容，并且在可检查认证时已认证。
- **需要认证** (`INSTALLED_NOT_AUTHENTICATED`)：命令存在，但提供商报告需要登录。
- **已安装但不健康** (`INSTALLED_BUT_UNHEALTHY`)：已安装，但不兼容或未通过其健康/版本检查。
- **CLI 未安装** (`NOT_INSTALLED`)：未找到 ThreadCells 运行时用户所用的规范可执行文件。
- **就绪状态未经验证** (`UNKNOWN`)：已安装且未被证明不可用，但提供商无法以非交互方式安全验证认证或就绪状态。

若提供商的命令已安装、兼容，且唯一未知项是认证状态，则即使未验证也可保持可启动。启动仍可能因提供商原生的登录提示而失败；请检查其终端并在 ThreadCells 外完成提供商认证。

## 检查运行时用户看到的环境

提供商可用性取决于运行 ThreadCells 的账户，而不是你的交互式 shell。请先通过 ThreadCells 检查：

```bash
threadcells providers list
threadcells doctor
```

然后以运行时用户身份验证预期的二进制文件和版本。以 Codex 为例：

```bash
command -v codex
codex --version
codex login status
```

在提供商有自身状态命令时请使用它。不要将个人提供商凭据目录复制到服务账户。请使用提供商支持的流程认证该账户。

## Settings 和 Spawn Agent

Settings → Providers 是清单和诊断视图。它显示适配器标识、配置、能力、命令是否存在、版本、认证状态及可安全公开的预检消息。

Spawn Agent 是启动视图。它从同一预检结果推导启用/禁用状态。若刷新后两个视图不一致，应将其视为产品缺陷，而不是猜测哪个标签正确。

## 能力因提供商而异

适配器会声明是否支持恢复、结构化完成、模型选择、推理控制、会话持久化和用量，或者这些能力是有条件支持或不支持。ThreadCells 不会模拟不受支持的功能。

Codex 是参考适配器，并为受支持的 token 字段提供精确的累计用量遥测。Claude Code 有条件地支持部分用量和完成能力。其他适配器可能不报告用量；其 Statistics 字段将保持不可用，而不会被估算。

## 配置和密钥

提供商配置是声明式的。它可以选择已安装的适配器及适配器自有设置，但不能导入二进制路径、shell 命令、参数、环境变量、密码、token 或原始凭据。

不透明的 `secret_refs` 可以命名由受信任适配器代码解析的密钥。公开的列表和导出响应会省略或脱敏其值。提供商适配器包是可执行的受信任代码，必须由主机操作员安装和审查。

## 故障排除

### 提供商显示 CLI 未安装

以服务账户身份运行 `command -v`，并将其 `PATH` 与你的 shell 比较。仅在你打算使用时安装规范的提供商命令，然后重启或刷新预检。

### 已安装但需要认证

以运行时用户身份运行提供商官方登录流程。ThreadCells 预检绝不会代你认证，也绝不会启用绕过权限的设置。

### 就绪状态未经验证

命令存在，但没有安全的非交互式就绪探测。请检查版本并执行一次小型提供商原生测试。一次 ThreadCells 启动可能是首次确定性的就绪检查。

### 已安装但不健康

阅读安全的预检原因。常见原因包括版本命令失败、已知不兼容的版本，或异常退出的可执行文件。请升级或修复外部 CLI；不要编辑适配器注册表来将其标为就绪。

### 显示就绪但启动失败

打开终端输出。凭据可能在预检后过期，所选模型可能不可用，或者提供商服务健康状况已改变。

高级集成详情请参阅[提供商适配器编写](PROVIDER_ADAPTERS.md)。有关启动配置文件控制的内容，请参阅[配置文件](PROFILES.md)。
