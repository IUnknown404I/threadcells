# ThreadCells へのコントリビューション

ThreadCells の改善にご協力いただきありがとうございます。焦点が明確で、実行可能であり、公開して安全に議論できるレポートとプルリクエストを歓迎します。

## 適切な経路を選ぶ

- **バグ:** 再現手順または永続的な証拠を添えて、[バグ報告フォーム](https://github.com/IUnknown404I/threadcells/issues/new?template=bug.yml) を使用してください。
- **機能強化:** [機能要望フォーム](https://github.com/IUnknown404I/threadcells/issues/new?template=feature.yml) を使用し、問題またはユースケースから始めてください。
- **ドキュメント:** 不足、古い、または不明確な公開ガイダンスについては、[ドキュメント報告フォーム](https://github.com/IUnknown404I/threadcells/issues/new?template=docs.yml) を使用してください。
- **質問とトラブルシューティング:** [ドキュメント](https://iunknown404i.github.io/threadcells/docs/) と [Troubleshooting](docs/TROUBLESHOOTING.md) を確認してから、[Discussions Q&A](https://github.com/IUnknown404I/threadcells/discussions/categories/q-a) で質問してください。
- **初期段階のアイデア:** [Discussions Ideas](https://github.com/IUnknown404I/threadcells/discussions/categories/ideas) で、問題またはユースケースから始めてください。成果が具体的かつ実行可能で、Issue ポリシーに沿う場合にのみ Issue へ移します。
- **セットアップとユースケース:** ワークフロー、統合、スクリーンショット、学びを [Show and tell](https://github.com/IUnknown404I/threadcells/discussions/categories/show-and-tell) で共有してください。
- **セキュリティ:** 公開 Issue を作成しないでください。[SECURITY.md](SECURITY.md) に従い、非公開で報告してください。

新しいスレッドまたはレポートを始める前に、既存の [Discussions](https://github.com/IUnknown404I/threadcells/discussions) またはオープン／クローズ済みの [Issues](https://github.com/IUnknown404I/threadcells/issues) を検索してください。詳細な Issue の適格性、証拠、トリアージ、開示ルールは、正規の [Issue ポリシー](docs/ISSUES.md) にあります。

## プルリクエスト

プルリクエストを開く前に、次を行ってください。

1. 最新の `main` から始め、重複する Issue とプルリクエストを確認します。
2. 変更の範囲を限定します。大きな作業はまず Issue で議論してください。
3. 動作が変わる場合は、対象を絞ったテストとドキュメントを追加または更新します。
4. 関連するローカルチェックを実行し、その結果をプルリクエストに記載します。
5. 認証情報、プライベートパス、個人データ、本番状態、またはターミナル記録を含めないでください。
6. 明確なコミットメッセージを使用し、レビューと CI フィードバックに対応します。

ThreadCells は独立した技術プレビューです。公開コラボレーションは敬意を払い、安全に開示できる情報に限定してください。コントリビューションのライセンスについては [LICENSE](LICENSE) を参照してください。
