# Procedencia

ThreadCells es un proyecto descendiente independiente derivado de AWS Labs CLI Agent Orchestrator. La licencia y la atribución de upstream conservadas están en los archivos `LICENSE` y `NOTICE` del candidato fuente. Este repositorio conserva nombres y comandos internos `cao` compatibles cuando preservan el comportamiento existente; las superficies públicas del producto usan ThreadCells. No se implica patrocinio ni respaldo de AWS.

Cada candidato local registra su revisión de código fuente confirmada, manifiesto de archivos, sumas de comprobación SHA-256 y evidencia de dependencias directas en `candidate-manifest.json`, `SHA256SUMS` y `sbom.cdx.json`. El SBOM es evidencia de dependencias directas declaradas/resueltas, no una autorización de licencias, evaluación de vulnerabilidades ni declaración de paridad con upstream. La distribución pública sigue requiriendo aprobación del propietario para el repositorio público, el contacto de seguridad, la procedencia de la marca y la revisión de dependencias/licencias.
