# Git authority

Never write exact `main` or `master`. No rebase, reset, clean, stash, amend, force push, branch deletion, or remote publication without explicit owner authority. Preserve unrelated changes and commit coherent local work only.

Protected-default-branch enforcement is repository-owner administration, not public project debt. The owner should require pull requests and canonical checks and disable force pushes and branch deletion through repository settings. If enforcement is missing, report it through the owner operational channel rather than creating a public Issue.
