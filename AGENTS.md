# Agent guide

ThreadCells is a self-hosted coding-agent operations console. Canonical public prose is the root README/Quick Setup and allowlisted `docs/DOCS_MANIFEST.json`; generated bundles are derived artifacts. Do not change protected branches, rewrite history, publish remotely, activate production, or include private state, credentials, private paths, domains, or personal data. Keep `cao*` internals compatible and use ThreadCells for public copy. Run focused checks for changed code and one meaningful integrated check before release work. Before creating a public Issue, follow `agents/policies/ISSUE_GOVERNANCE.md` and the canonical `docs/ISSUES.md`. Publication, production activation, security contact, public remote, and breaking namespace changes require an owner decision. See `agents/policies/` for concise detail.
